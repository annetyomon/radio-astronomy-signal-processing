# Radio Astronomy Signal Processing with Python

This project demonstrates basic signal processing techniques using Python to analyze a simulated radio astronomy observation.

## Project Overview

The project uses a simulated radio observation and applies the Fast Fourier Transform (FFT) to examine the signal in the frequency domain. The resulting frequency spectrum is visualized to identify the frequency components present in the observation.

## Methods Used

* Fast Fourier Transform (FFT)
* Frequency-domain analysis
* Signal and noise analysis
* Frequency-spectrum visualization
* Simulated radio astronomy observation

## Technologies Used

* Python
* NumPy
* Matplotlib
* Jupyter Notebook

## Key Analysis

The FFT converts the simulated radio observation from the time domain into the frequency domain. The magnitude of the frequency components is then calculated and plotted for positive frequencies.

## Purpose

This project is part of my exploration of signal processing, radio astronomy, and scientific computing. It demonstrates how Python can be used to analyze and visualize signals relevant to radio astronomy.
